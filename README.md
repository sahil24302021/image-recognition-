# 🖼️ Image Recognition App

A simple **Streamlit web app** that uses **TensorFlow’s MobileNetV2** model to recognize objects in images.  
Upload an image, and the app will tell you what it sees — powered by deep learning and the ImageNet dataset.

---

## 🚀 Demo

🧠 **Try it yourself!**  
Upload a `.jpg`, `.jpeg`, or `.png` image and see what the AI predicts.

---

## 🧩 Features

✅ Built with **Streamlit** for an interactive web UI  
✅ Uses **TensorFlow Keras MobileNetV2**, pre-trained on **ImageNet**  
✅ Displays top-3 predicted classes with confidence scores  
✅ Lightweight and fast – no retraining required
